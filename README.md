# Vertigo

Vertigo is a *Doodle jump*-style game with a techno arcade
aesthetic, developed in C++ with [sflm](https://www.sfml-dev.org/).

You control a cube that must jump through blocks. Dont fall and try to survive as long as
possible.

The game is single player.

> Assignment for **Práctica Profesional I: Desarrollo de Videojuegos
> I**, Image Campus, 2026.

## Controls

  Key          Action
  ------------ ----------------------
  left or A    move left
  right or B   move right
  Esc          Return to the menu
